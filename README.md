# TWODRAPES 订单工具

窗帘/帘布定制产品的订单管理、成本核算、利润计算和工厂反馈工具。数据保存到 SQLite，局域网内多台电脑共享产品、参数和订单。

## 安装与启动

```powershell
cd C:\Users\Administrator\Desktop\twodrapes-factory-tool
npm.cmd install
npm.cmd start
```

**要求：** Node.js 24+（内置 `node:sqlite`，无需安装 C++ 构建工具）。

启动后同时运行四个服务：

| 端口 | 用途 | 地址 |
|------|------|------|
| 8080 | 独立站端 (Shopify) | `http://localhost:8080` |
| 8081 | 管理端 | `http://localhost:8081` |
| 8082 | 亚马逊端 (Amazon) | `http://localhost:8082` |
| 8083 | 登录页 | `http://localhost:8083` |

局域网访问：将 `localhost` 替换为服务器局域网 IP。

## 四端架构

### 独立站端（8080）/ 亚马逊端（8082）

两个运营端共用同一套前端代码（`public/` 目录），通过 URL 端口自动检测渠道。8080 为 Shopify 渠道，8082 为 Amazon 渠道。两个端口的数据通过渠道字段区分，各自只能看到本渠道的订单。

**功能页面：**
- **下单** — 客户信息、产品选择、实时价格预览、剪贴板批量解析、折扣计算
- **订单** — 订单列表（支持展开查看项目颜色/面料/尺寸）、编辑、导出、CSV 导入、批量操作
- **产品控制** — 产品 CRUD、价格表、选项组编辑、Easify CSV 导入
- **拼接计算器** — 裁法计算、用料估算
- **利润计算** — 单订单利润明细、金额修正、工厂成本反馈导入

**渠道检测原理：** 前端通过 `location.port` 运行时判断当前渠道。修改 `public/` 中的任意文件，两个端口同步生效。

### 管理端（8081）

面向管理层的汇总视图。可查看所有渠道订单、利润详情、导入工厂成本反馈、控制全局公式参数。

**功能页面：**
- **订单汇总** — 全渠道订单列表，按渠道/状态/搜索筛选，统计卡片，点击订单号查看订单详情（项目按产品分组展示）
- **利润计算** — 选择订单查看利润明细和项目成本拆解
- **参数设置** — 全局参数、面料/内衬、加工费/定型费规则的增删改查
- **用户管理** — 运营端登录用户的增删改查

## 认证

三端共用 JWT 认证体系。默认免登录（`NO_AUTH=1`），可通过环境变量启用：

```powershell
$env:NO_AUTH="0"
$env:ADMIN_PASSWORD="your_password"
npm.cmd start
```

启用后访问任意端口会自动跳转到登录页（8083），输入用户名密码获取 JWT token，后续请求自动携带。

**认证方式：**
- **JWT Bearer Token** — 登录后获取，通过 `Authorization: Bearer <token>` 传递
- **HTTP Basic Auth** — 备用方式，通过 `Authorization: Basic <base64(user:pass)>` 传递，使用管理员凭据

**安全限制：** 登录接口有频率限制，10 分钟内最多 20 次尝试。

## 数据位置

| 路径 | 说明 |
|------|------|
| `./data/twodrapes.sqlite` | SQLite 数据库 |
| `./data/backups` | 自动/手动备份 |

本项目使用 Node.js 24 自带的 `node:sqlite`（`DatabaseSync`，同步 API），不需要安装 Visual Studio C++ 构建工具。启动时看到 SQLite experimental warning 属于 Node 当前提示，不影响使用。

## 运营端功能

### 下订单

1. 填写订单信息（订单号、客户姓名/邮箱/电话、收货地址）
2. 选择下单日期，交期默认为空（后续填入）
3. 选择产品、输入尺寸（Width/Length inch）、数量、褶皱倍率
4. 选择产品选项（颜色、挂钩工艺、内衬等），实时预览价格和折扣
5. 点击"添加到当前订单"，支持继续录入（保留选项，仅清除尺寸）
6. 一个订单可包含多个项目，保存订单到数据库

**剪贴板解析：** 点击"信息匹配"，粘贴订单信息，自动识别并填充客户字段（订单号、姓名、邮箱、电话、地址）。

### 订单

- 表格展示当前渠道订单，项目列按产品分组紧凑展示
- 订单状态：草稿 → 待生产 → 待发货 → 完成
- 支持搜索、日期范围筛选、状态筛选、产品筛选
- 批量操作：批量导出 CSV、批量重新计算、批量删除
- 点击订单号打开详情弹窗，查看完整订单信息和项目明细
- 编辑模式可修改客户信息、物流信息、项目数量、选项值（所有状态均可编辑）
- 物流信息：货代、尾程派送渠道、尾程追踪编码、送达日期、重量 KG、物流成本

### 产品控制

- 产品选择、保存、复制、删除
- 基础信息：名称、默认主面料、基础价、每单位片数（`panels_per_unit`）
- Width/Length 价格表：可新增/删除价格档位
- 产品选项组：支持拖拽排序，每个选项组可配置多个选项值（标签/售价USD/成本RMB）
- 导入：Easify CSV 导入、产品 CSV 导入、下载模板

### 利润计算

- 选择订单加载利润明细（销售额、税费、收入、物流成本、总成本、利润率）
- 调整参数重算：物流成本、销售 USD 覆盖、税费 USD 覆盖
- 项目利润明细表
- 成本诊断：系统预计 vs 工厂成本 vs 最终采用成本对比

## 管理端功能

### 订单汇总

- 全渠道订单统计（总订单数、总售价、总成本、总利润、平均利润率）
- 按渠道、状态、关键词筛选
- 表格展示：订单号（可点击查看详情）、客户、交期、渠道、状态、售价、成本、利润、利润率
- 订单详情弹窗：基础信息、物流信息、项目按产品分组展示（每组显示项目数和总条数）

### 利润计算

- 选择订单查看利润明细（含项目级别成本拆解）
- 参数调整重算

### 参数设置

- 全局参数：上包衬余量、底边余量、发料安全余量、用料进位、拼接费等
- 面料管理：名称、系列、门幅、单价
- 内衬管理：名称、颜色、门幅、单价
- 加工费规则：层数、高度分档、单价
- 定型费规则：高度分档、单层价、双层系数

### 用户管理

- 运营端用户增删改查
- 按渠道筛选
- 启用/停用状态控制

## 订单金额口径

| 字段 | 说明 |
|------|------|
| 实际销售 USD | 销售 USD（不含税）+ 税费 USD |
| 实际销售 RMB | 实际销售 USD × 6.8 |
| 扣手续费后收入 RMB | 实际销售 USD × (1 - 4.4%) × 6.8 |
| 利润 RMB | 扣手续费后收入 RMB - 最终成本 RMB |
| 最终成本 RMB | 订单项目最终采用成本合计 + 物流成本 |

## 成本计算口径

系统下单时自动计算"系统预计成本"。工厂反馈导入后，按优先级生成"最终采用成本"：

1. 有"结算" → 使用工厂结算
2. 无结算但有"工厂成本合计" → 使用工厂成本合计
3. 无工厂反馈 → 使用系统预计成本

**预计成本拆分：** 主面料成本、内衬成本、加工费、拼接费、定型费、选项成本、物流成本、成本合计。

**内衬成本：** 工厂反馈支持独立的内衬用料和成本录入（内衬材料、实际用料、单价、加工费、定型费、成本合计、结算），与主面料成本分开计算后合并。

**默认参数：**

| 参数 | 默认值 | 用途 |
|------|--------|------|
| 上包衬余量 | 10 cm | 面料理论用料 |
| 底边余量 | 5 cm | 面料理论用料 |
| 发料安全余量 | 50 cm | 仅发料成本，不影响加工/定型/拼接 |

高度分档使用下单成品高度，加工费按计费宽度计算，拼接费单独列出。订单详情显示"成本诊断"，对比系统预计、工厂成本、最终采用成本及差异。

## 工厂反馈流程

1. 运营端或管理端在"利润计算"页导出加工费用确认单 XLSX
2. 工厂填写实际用料、面料单价、加工费、定型费、成本合计、结算、完成时间、备注（含内衬明细）
3. 运营端或管理端导入填写后的 XLSX，系统按"品名/编号"自动匹配订单项目
4. 系统按优先级确定最终成本（结算 > 成本合计 > 系统预计）

## API 端点

### 订单

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/orders?channel=` | 订单列表（可按渠道筛选），含嵌套项目 |
| GET | `/api/orders/:id` | 单个订单详情 |
| POST | `/api/orders` | 创建订单 |
| PUT | `/api/orders/:id` | 更新订单（所有状态均可编辑） |
| DELETE | `/api/orders/:id` | 删除订单（级联删除项目和反馈） |
| PUT | `/api/orders/:id/status` | 更新订单状态 |
| POST | `/api/orders/:id/recalculate` | 重新计算订单 |
| PUT | `/api/orders/:id/logistics` | 设置物流成本并重算 |
| PUT | `/api/orders/:id/financial` | 设置销售/税费覆盖或清除（`clear: true`），然后重算 |
| POST | `/api/orders/recalculate-all` | 重新计算所有订单 |

### 订单项目

| 方法 | 路径 | 说明 |
|------|------|------|
| PUT | `/api/order-items/:id/option` | 更新单个选项值，自动重算订单 |
| PUT | `/api/order-items/:id/qty` | 更新项目数量，自动重算订单 |

### 其他

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/bootstrap` | 初始化数据（产品、面料、参数等） |
| POST | `/api/auth/login` | 登录获取 JWT |
| GET | `/api/health` | 健康检查 |

## 数据库表结构

| 表名 | 说明 |
|------|------|
| `orders` | 订单主表（渠道、状态、客户信息、物流、金额汇总） |
| `order_items` | 订单项目（产品、尺寸、面料、选项、成本） |
| `products` | 产品定义 |
| `product_option_groups` | 产品选项组（颜色、挂钩样式等） |
| `product_option_values` | 选项值（含售价和成本） |
| `product_width_prices` / `product_length_prices` | 产品尺寸价格表 |
| `fabrics` | 面料（名称、系列、门幅、单价） |
| `linings` | 内衬（名称、颜色、门幅、单价） |
| `labor_rules` | 加工费规则 |
| `memory_rules` | 定型费规则 |
| `globals` | 全局参数 |
| `tax_rates` | 各州税率 |
| `factory_feedback` | 工厂反馈（主面料和内衬的实际用料、成本、结算） |
| `users` | 登录用户 |
| `backups` | 备份记录 |

**订单状态：** `draft`（草稿）→ `production`（待生产）→ `shipping`（待发货）→ `completed`（完成）

## 注意事项

- `localStorage` 只用于当前订单草稿，不是正式数据源
- 正式订单、产品、参数都写入服务器 SQLite
- 税率为参考平均值，实际以客户地址/ZIP 为准
- 销售汇率固定 `6.8`，PayPal 手续费固定 `4.4%`（可通过环境变量调整）
- 启用认证时必须设置 `ADMIN_PASSWORD` 环境变量
- JWT 密钥自动生成并保存在 `data/.jwt-secret`，备份时请一并备份
- 管理端不包含产品控制和 Shopify 集成页面
- 运营端修改 `public/` 中的文件后两个端口（8080/8082）同步生效，无需重启
